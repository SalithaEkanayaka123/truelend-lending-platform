## User Story
As a user, I want Apply wizard and verification queue UI so that the milestone advances.

## Business Value
The two demo-critical screens on the customer and underwriter sides of document intake: a mobile-friendly apply wizard and a responsive verification queue.

## Description
Apply wizard and verification queue UI

## Scope
**In:** a three-step apply wizard (Product, Details, Documents and submit) with a progress indicator; inline range validation on the Details step; a verification queue that renders as a table on desktop and stacked cards on mobile, updating without a page reload
**Out:** real file upload UI beyond a stub form

## Acceptance Criteria
- **E2-S4-AC1** — *Given* a customer on a 375x812 viewport, *when* they apply, *then* a three-step flow (Product, Details, Documents and submit) shows one step at a time with a progress indicator and no horizontal scroll.
- **E2-S4-AC2** — *Given* the Details step, *when* they enter tenure 72 for PERSONAL, *then* an inline error shows "12-60 months" before they continue.
- **E2-S4-AC3** — *Given* an underwriter on 1280x800, *when* they open the queue, *then* a table lists documents; at 375x812 the same data shows as stacked cards; verifying one removes it without a page reload.
