## User Story
As a user, I want Upload documents and submit so that the milestone advances.

## Business Value
An application only becomes decision-ready once the required documents are recorded and the customer submits, pinning the policy version used for underwriting.

## Description
Upload documents and submit

## Scope
**In:** POST .../documents recording metadata only (type, filename), no file content; POST .../submit requiring every document UPLOADED or later, pinning the active policy version; re-upload of a REJECTED document resets it to UPLOADED
**Out:** real file storage, OCR, or virus scanning; editing an application after submission

## Acceptance Criteria
- **E2-S3-AC1** — *Given* application 1 in DRAFT, *when* the owner POSTs {type:"ID_PROOF", filename:"id_front.png"}, *then* it is 201 and that document is UPLOADED with no file content stored.
- **E2-S3-AC2** — *Given* PERSONAL application 1, *when* they POST type VEHICLE_QUOTATION, *then* it is 422 DOCUMENT_TYPE_NOT_REQUIRED.
- **E2-S3-AC3** — *Given* SALARY_SLIP is still MISSING, *when* they POST submit, *then* it is 409 MISSING_DOCUMENTS with missing ["SALARY_SLIP"] and status stays DRAFT.
- **E2-S3-AC4** — *Given* all 3 documents UPLOADED and the active version 1, *when* they POST submit, *then* it is 200, status SUBMITTED, policy_version 1, and submitted_at set.
- **E2-S3-AC5** — *Given* an already SUBMITTED application, *when* submit is posted again, *then* it is 409 ALREADY_SUBMITTED.
