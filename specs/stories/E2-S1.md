## User Story
As a user, I want Product catalog from the active policy so that the milestone advances.

## Business Value
A customer must see the loan products and their thresholds before applying; the catalog is read live off whichever policy version is currently approved.

## Description
Product catalog from the active policy

## Scope
**In:** GET /api/products returning the active version's PERSONAL/VEHICLE/EDUCATION thresholds and required_documents; startup verification that policy_v0001.json matches its stored SHA-256
**Out:** creating or approving policy versions (E4-S1); a fourth product type

## Acceptance Criteria
- **E2-S1-AC1** — *Given* seeded policy version 1, *when* an authenticated user GETs /api/products, *then* exactly 3 products return (PERSONAL, VEHICLE, EDUCATION), each with policy_version 1.
- **E2-S1-AC2** — *Given* version 1, *when* the rule sets are compared pairwise, *then* each differs in at least one threshold (min_income is 25000.00, 30000.00, 20000.00).
- **E2-S1-AC3** — *Given* version 1, *when* the catalog is read, *then* required_documents has 3 entries for PERSONAL and 4 each for VEHICLE and EDUCATION.
- **E2-S1-AC4** — *Given* no token, *when* GET /api/products is requested, *then* it is 401.
- **E2-S1-AC5** — *Given* policy_v0001.json edited on disk, *when* the app starts, *then* startup aborts with POLICY_CHECKSUM_MISMATCH.
