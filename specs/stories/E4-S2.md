## User Story
As a user, I want Policy editor UI so that the milestone advances.

## Business Value
Lets a policy editor change thresholds through a form instead of a file, with validation that prevents an invalid draft from ever being saved.

## Description
Policy editor UI

## Scope
**In:** per-product threshold forms stacking in one column on mobile; inline validation (e.g. min_age < max_age) disabling Save until fixed; a draft-version confirmation after Save
**Out:** approving a version from this UI (admin action, out of this story's scope_in)

## Acceptance Criteria
- **E4-S2-AC1** — *Given* a POLICY_EDITOR on a 375x812 viewport, *when* they open the policy editor, *then* the product forms stack in one column with no horizontal scroll.
- **E4-S2-AC2** — *Given* the PERSONAL form, *when* they enter min_age 70 with max_age 60, *then* an inline error appears before submit and the Save button is disabled.
- **E4-S2-AC3** — *Given* valid changes, *when* they Save, *then* the page shows "Draft v2" and the new version appears in the list.
