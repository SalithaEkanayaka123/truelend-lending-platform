## User Story
As a user, I want Create and approve policy versions so that the milestone advances.

## Business Value
Lets a policy editor adjust thresholds without a code change, while keeping every approved version immutable and auditable, and letting only an admin activate a new one.

## Description
Create and approve policy versions

## Scope
**In:** POST /api/policies creating a new DRAFT version file, byte-identical predecessor; POST /api/policies/{version}/approve, ADMIN only, activating the highest-numbered APPROVED version; validation of rate/age/tenure/amount/score ranges before a file is written; no PUT/PATCH/DELETE route on /api/policies*; a DB trigger aborting any other UPDATE
**Out:** a fourth product type; editing score weights through the policy editor; rolling back an approved policy version

## Acceptance Criteria
- **E4-S1-AC1** — *Given* POLICY_EDITOR user 2, *when* they POST /api/policies with base_version 1 and PERSONAL.min_income "30000.00", *then* it is 201 with version 2, status DRAFT, file policy_v0002.json written, an audit row POLICY_CREATED, and the SHA-256 of policy_v0001.json unchanged.
- **E4-S1-AC2** — *Given* version 2 is DRAFT, *when* GET /api/products, *then* PERSONAL min_income is still "25000.00" and policy_version is 1.
- **E4-S1-AC3** — *Given* ADMIN user 1, *when* they POST /api/policies/2/approve, *then* it is 200 APPROVED with approved_by 1, an audit row POLICY_APPROVED, and GET /api/products shows PERSONAL min_income "30000.00" with policy_version 2.
- **E4-S1-AC4** — *Given* approved version 1, *when* PUT, PATCH, or DELETE hits /api/policies/1, or a raw SQL UPDATE changes its thresholds, *then* the HTTP verbs return 405 and the SQL UPDATE aborts at the database.
- **E4-S1-AC5** — *Given* POLICY_EDITOR user 2, *when* they POST /api/policies/2/approve, *then* it is 403.
- **E4-S1-AC6** — *Given* a change setting auto_reject_below_score 750 with auto_approve_min_score 700, or min_income "-1", *when* POSTed, *then* it is 422 VALIDATION_ERROR naming the offending field and no file is written.
