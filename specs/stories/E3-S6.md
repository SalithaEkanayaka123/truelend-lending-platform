## User Story
As a user, I want Decision review and override UI so that the milestone advances.

## Business Value
Gives an underwriter the score, reason codes, and policy context needed to resolve a MANUAL_REVIEW or decide an override, on desktop and mobile.

## Description
Decision review and override UI

## Scope
**In:** a decision panel showing score, reason codes with customer-readable messages, and policy version; an override dialog requiring both a reason code and a comment before Submit enables; review Approve/Reject buttons disabled until a reason is entered
**Out:** the admin-only application list/filter view (FR-10, deferred to M2)

## Acceptance Criteria
- **E3-S6-AC1** — *Given* an underwriter opening application 2, *when* the page loads, *then* it shows score 680, the reason code with its message, and policy version 1; at 375x812 the panels stack with no horizontal scroll.
- **E3-S6-AC2** — *Given* the override dialog on an AUTO_REJECT application, *when* the comment is empty or no reason code is chosen, *then* Submit is disabled; with both set it enables and success shows a confirmation.
- **E3-S6-AC3** — *Given* a MANUAL_REVIEW application, *when* the reason field is empty, *then* Approve and Reject are disabled.
