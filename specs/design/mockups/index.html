TrueLend — M1 mockups

Interactive HTML mockups for the three UI-layer stories in scope (E2-S4, E3-S6, E4-S2). See aesthetic-direction.md for the visual direction these follow.

  • E2-S4 — Apply wizard and verification queue
    Screens: Apply: Product · Apply: Details · Apply: Documents and submit · Verification queue. Endpoints: GET /api/products, POST /api/applications, POST /api/applications/{id}/documents, POST /api/applications/{id}/submit, GET /api/verification-queue, POST /api/documents/{id}/verify.
  • E3-S6 — Decision review and override
    Screens: Decision panel with score gauge and reason codes · Review actions (Approve/Reject) · Override dialog. Endpoints: GET /api/applications/{id}, POST /api/applications/{id}/review, POST /api/applications/{id}/override.
  • E4-S2 — Policy editor
    Screens: Per-product threshold forms (Personal, Vehicle, Education) · Version list. Endpoints: GET /api/policies, GET /api/policies/{version}, POST /api/policies.
